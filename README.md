# CC Vocabulary Theme (Sverige)

WordPress theme implementation of the Vocabulary design system, as used on
[creativecommons.se](https://creativecommons.se/). Creative Commons Sverige
build of [creativecommons/vocabulary-theme][upstream].

[upstream]: https://github.com/creativecommons/vocabulary-theme

**Advanced Custom Fields (free edition, 6.1 or later) is required.** Without it
none of the theme's custom post types, taxonomies or fields are registered.

- [Installation and site setup][install]
- [Cutting a release][release]
- [Source repository][repo]

[install]: https://github.com/okfse/vocabulary-theme/blob/main/docs/INSTALL.md
[release]: https://github.com/okfse/vocabulary-theme/blob/main/docs/RELEASE.md
[repo]: https://github.com/okfse/vocabulary-theme

Theme development happens in the `src/` directory of the source repository;
`scripts/prepare-release.sh` moves its contents to the archive root so the
package is a valid WordPress theme.
